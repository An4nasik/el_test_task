# API Documentation

## Общая информация

**Базовый URL:** `http://<host>:8000/api/v1`

**Авторизация:** Все эндпоинты требуют заголовок `X-API-Key` с валидным API ключом.

**Формат данных:** JSON

## Эндпоинты

---

### POST /ask/text

Отправка текстового запроса с опциональным изображением.

#### Заголовки

| Заголовок | Тип | Обязательный | Описание |
|-----------|-----|--------------|----------|
| X-API-Key | string | Да | API ключ авторизации |
| Content-Type | string | Да | application/json |

#### Тело запроса

```json
{
  "user_id": "string",
  "text": "string",
  "image_base64": "string | null"
}
```

| Поле | Тип | Обязательный | Описание |
|------|-----|--------------|----------|
| user_id | string | Да | Уникальный идентификатор пользователя |
| text | string | Да | Текст вопроса |
| image_base64 | string | Нет | Изображение в формате base64 |

#### Ответ

**Код 200:**
```json
{
  "user_id": "string",
  "response": "string"
}
```

**Код 400:**
```json
{
  "detail": "Invalid image base64"
}
```

**Код 401:**
```json
{
  "detail": "Invalid API key"
}
```

#### Пример запроса

```bash
curl -X POST "http://localhost:8000/api/v1/ask/text" \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"user_id": "user123", "text": "Кто такой Воланд?"}'
```

### POST /ask/audio

Отправка аудио запроса с опциональным изображением.

#### Заголовки

| Заголовок | Тип | Обязательный | Описание |
|-----------|-----|--------------|----------|
| X-API-Key | string | Да | API ключ авторизации |
| Content-Type | string | Да | application/json |

#### Тело запроса

```json
{
  "user_id": "string",
  "audio_base64": "string",
  "image_base64": "string | null"
}
```

| Поле | Тип | Обязательный | Описание |
|------|-----|--------------|----------|
| user_id | string | Да | Уникальный идентификатор пользователя |
| audio_base64 | string | Да | Аудио файл (MP3/OGG) в формате base64 |
| image_base64 | string | Нет | Изображение в формате base64 |

#### Ответ

**Код 200:**
```json
{
  "user_id": "string",
  "response": "string"
}
```

**Код 400:**
```json
{
  "detail": "Invalid audio base64"
}
```

**Код 401:**
```json
{
  "detail": "Invalid API key"
}
```

#### Пример запроса

```bash
# Кодирование аудио файла в base64
AUDIO_BASE64=$(base64 -w 0 question.mp3)

curl -X POST "http://localhost:8000/api/v1/ask/audio" \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d "{\"user_id\": \"user123\", \"audio_base64\": \"$AUDIO_BASE64\"}"
```

## Коды ошибок

| Код | Описание |
|-----|----------|
| 200 | Успешный запрос |
| 400 | Некорректные данные запроса |
| 401 | Неверный API ключ |
| 422 | Ошибка валидации данных |
| 500 | Внутренняя ошибка сервера |

## Примечания

1. **Контекстная память**: Система хранит последние 10 сообщений для каждого `user_id`. Это позволяет задавать уточняющие вопросы.

2. **Изображения**: При отправке изображения оно анализируется Vision моделью, и описание добавляется к контексту запроса.

3. **Аудио**: Поддерживаются форматы MP3 и OGG. Аудио транскрибируется локально с помощью Whisper.

4. **База знаний**: Ответы формируются на основе информации из векторной базы, созданной из загруженных документов.
